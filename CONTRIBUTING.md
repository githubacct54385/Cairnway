# Contributing

Thank you for helping. Please read this first: reviews happen in batches as time permits, and there is no promised
response time.

## Suggesting a correction or addition

Open an issue using the "Suggest a correction or addition" template. Say which era, what should change, and what source
supports it. Please do not paste long passages from copyrighted works.

## Sending a change

1. Fork or branch, and make your change.
2. Open a pull request and fill in the checklist.
3. If the build passes, a pull request from a branch in this repository is merged automatically.
   Pull requests from forks are reviewed by hand.

## Content rules

- Write in your own words. Do not copy text from sources.
- Every claim gets a visible citation.
- Every new source, image or dataset goes in `SOURCES.md` with its license, a link, and the date you checked it.
- Prefer public domain or openly licensed material. If a license is unclear, link to the source instead of reproducing it.
- Do not add text from share-alike sources such as Wikipedia.
- Where scholars or traditions disagree, say so and attribute each view to its source. Use neutral, descriptive language.
- Show the evidence and name who holds each view, rather than writing that the page "does not take a side".
- In the history sections, statements of Christian belief are attributed (for example, "Christians have traditionally
  read…") and never written in the page's own voice. The site's own perspective is stated once, on the About page.

## Licensing your contribution

By contributing you confirm you have the right to submit your work and agree it is licensed under MIT (code) or
CC BY 4.0 (original text), as described in the README.
